# autosave — 흑백·노후 사진 AI 복원 파이프라인

스캔하거나 휴대폰으로 촬영한 옛 사진(액자 상태 포함)을 **로컬 CPU에서** 복원하는 파이프라인입니다.
GPU, API 키, 외부 서비스 업로드가 필요 없으며, 모든 가중치는 공개된 ONNX 배포본을 최초 1회 내려받아 캐시합니다.

## 1. 배경 (Why)

노후 사진의 열화는 성격이 다른 4가지 문제가 겹쳐 있어 단일 모델로는 해결되지 않습니다.

| 열화 유형 | 실제 증상 | 단일 모델로 안 되는 이유 |
|---|---|---|
| 촬영/스캔 아티팩트 | 액자 테두리, 조명 그라데이션, 색 틀어짐, JPEG 노이즈 | 신경망이 이를 "원본 정보"로 오인해 함께 증폭 |
| 얼굴 열화 | 초점 흐림, 디테일 손실 | 일반 SR 모델은 인물 정체성을 보존하지 못함 |
| 해상도 부족 | 인쇄물 재촬영으로 인한 저해상 | 얼굴 전용 모델은 배경·의상에 적용 불가 |
| 색 정보 부재 | 흑백/세피아 | 복원과 채색은 별개 태스크 |

## 2. 목표 (What)

원본의 **정체성과 계조를 보존**하면서 (1) 물리적 손상 제거, (2) 얼굴 복원, (3) 해상도 복원,
(4) 선택적 채색을 한 번의 실행으로 처리하고, 흑백 복원본과 컬러본을 동시에 산출합니다.

## 3. 실행 방법 (How)

```bash
pip install -r requirements.txt

# 파일 1장
python restore.py photo.jpg -o restored/

# 폴더 일괄 처리 (하위 폴더 포함)
python restore.py album/ -o restored/

# 흑백 복원만, 4배 확대
python restore.py photo.jpg -o restored/ --no-colorize --upscale 4
```

산출물은 `restored/<파일명>_bw.jpg`(흑백 복원), `_color.jpg`(채색), `_comparison.jpg`(원본/결과 비교)입니다.

### 주요 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--face-model` | `codeformer` | `codeformer` / `gfpgan` / `gpen` |
| `--fidelity` | `0.85` | CodeFormer `w`. **1.0에 가까울수록 실제 얼굴에 충실**, 낮을수록 깨끗하지만 인물이 달라짐 |
| `--face-blend` | `0.9` | 복원된 얼굴의 합성 불투명도 |
| `--upscale` | `2` | `1`(비활성) / `2` / `4` |
| `--neutralize` | `0.7` | 채색 결과의 전역 색 편향 보정 강도 |
| `--saturation` | `0.85` | 채색 채도 |
| `--no-flip-tta` | off | 좌우 반전 채색 패스 생략(약 16초 단축, 색 안정성 저하) |
| `--denoise` | `5` | Non-local means 강도 (`0`이면 비활성) |
| `--no-crop` | off | 액자 테두리 자동 제거 비활성화 |

모델 캐시 위치는 `PHOTO_RESTORE_MODELS` 환경 변수로 지정합니다(기본 `~/.cache/photo-restore`).

## 4. 파이프라인 구조

```
원본 → [A] 전처리 → [B] 얼굴 복원 → [C] 초해상 → [D] 채색 → 산출물
```

| 단계 | 처리 | 사용 모델 / 기법 |
|---|---|---|
| A. 전처리 (`preprocess.py`) | EXIF 회전 보정 → 액자 테두리 검출·제거 → 흑백 판정 → 조명 그라데이션 제거(flat-field) → NLM 노이즈 제거 → 블랙/화이트 포인트 재설정 + CLAHE → 액자 내측의 near-black 띠 제거 | 고전 영상처리 (OpenCV) |
| B. 얼굴 복원 (`faces.py`) | YOLOFace-8n 검출(5점 랜드마크) → FFHQ 512 정렬 → 블라인드 복원 → 휘도 정합 + 페더 마스크 합성 | `yoloface_8n`, `codeformer` (대안: `gfpgan_1.4`, `gpen_bfr_512`) |
| C. 초해상 (`upscale.py`) | 오버랩 타일 분할 → 코사인 램프 가중 합성(이음매 제거) | `real_esrgan_x2` / `real_esrgan_x4` |
| D. 채색 (`colorize.py`) | 휘도만 입력 → a/b 채널 예측(좌우 반전 TTA 평균) → 전역 색 편향 중화 → **원본 휘도 유지** 상태로 CIELAB 합성 | `ddcolor` |

### 설계상의 주요 결정

- **전처리를 신경망보다 먼저** 둡니다. 조명 얼룩과 색 틀어짐이 남은 상태로 복원 모델에 넣으면
  모델이 이를 피사체 특징으로 간주해 왜곡을 증폭합니다.
- **얼굴은 별도 좌표계에서 복원**합니다. 복원 모델은 FFHQ 512 정렬 공간에서 학습되었으므로,
  5점 랜드마크 기반 similarity transform으로 정렬한 뒤 역변환하여 되돌립니다.
- **합성 시 휘도 통계를 정합**합니다(`_match_luma`). 정합 없이 붙이면 얼굴만 밝기가 달라 패치처럼 보입니다.
- **채색은 휘도를 건드리지 않습니다.** a/b 채널만 교체하므로 원본 계조가 그대로 유지되며,
  흑백본과 컬러본의 명암이 동일합니다.
- **크로마는 초해상 *이전* 해상도에서 예측**합니다. 채색 모델은 촬영 해상도의 휘도 통계에 맞춰져 있어,
  초해상 후의 이미지를 입력하면 색상이 눈에 띄게 틀어집니다. 크로마는 저주파 신호이므로
  저해상도에서 예측한 a/b를 초해상된 휘도에 리샘플링해도 화질 손실이 없습니다.
- **좌우 반전 TTA**: DDColor의 편향은 좌우 대칭이 아니어서(본 사진에서는 한쪽 어깨만 마젠타로 물듦)
  원본과 좌우 반전 예측을 평균해 편향을 완화합니다.
- **흑백 판정은 색 편향에 불변**입니다. a/b 중앙값(전역 캐스트)을 제거한 뒤 잔여 채도의 75퍼센타일로
  판정하므로, 세피아·황변된 인화물은 흑백으로, 실제 컬러 사진은 컬러로 분기됩니다(측정값: 흑백 인화 약 5, 컬러 약 45+).
- **어두운 테두리 제거는 계조 정규화 *이후*** 실행합니다. 정규화 후에는 액자 내측 띠만 0에 가깝게 떨어지고
  실제 어두운 피사체(검은 정장, 비네팅된 배경)는 충분히 위에 남으므로, 사진 내용을 잘라내지 않고 띠만 제거됩니다.
- **채색 편향 보정**: DDColor는 스튜디오 인물 사진에서 화면 전체에 보라/마젠타 편향을 넣는 경향이 있습니다.
  a/b의 **중앙값**을 기준으로 보정하므로 면적이 큰 무채색 영역(배경·정장)은 중성으로 돌아오고,
  소수 영역인 피부·넥타이의 고유색은 유지됩니다.

## 5. 성능 (4코어 CPU, 1190×2576 기준)

| 단계 | 소요 |
|---|---|
| 전처리 | 약 8초 |
| 얼굴 복원 (1인) | 약 9초 |
| 초해상 ×2 (66 타일) | 약 3~4분 |
| 채색 (반전 TTA 포함 2패스) | 약 33초 |

초해상 ×4는 타일당 약 11초로 ×2 대비 3~4배 소요됩니다.

## 6. 한계 및 주의사항

- **복원 모델은 생성 모델입니다.** 원본에 없는 디테일은 통계적으로 그럴듯하게 만들어진 것입니다.
  `--fidelity`는 CodeFormer의 `w`로, 값이 클수록 열화된 원본에 충실합니다. 다만 `1.0`은 원본의
  초점 흐림까지 그대로 보존해 오히려 흐릿해지므로, 실측 비교 결과 `0.85`가 디테일과 정체성의
  균형점이었습니다. 인물의 실제 이목구비가 중요한 용도에서는 `0.85` 이상만 사용하시기 바랍니다.
- **채색된 색은 추정치입니다.** 실제 의상·배경 색과 일치한다는 보장이 없습니다.
- 심한 찢김·결손(구멍, 대면적 스크래치)은 인페인팅 모델이 별도로 필요하며 현재 범위 밖입니다.
- DeOldify ONNX 배포본은 입출력 규격이 달라 정상 출력을 얻지 못해 파이프라인에서 제외했습니다.
